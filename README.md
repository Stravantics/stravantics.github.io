# Stravantics — GitHub Pages site

A dependency-light, responsive static website for Stravantics.

## Deploy to GitHub Pages

1. Create a GitHub repository for the site.
2. Copy the contents of this package into the repository root.
3. Commit and push to the default branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your default branch and `/ (root)`, then save.

No build step is required.

## Customize

- Replace the GitHub URL in `index.html` with your actual profile/organization URL.
- Update copy as Cerebro evolves.
- Replace files in `assets/` if you create final brand assets.
- The contact CTA currently uses `software@stravantics.com`.

## Included brand assets

- `assets/stravantics-logo.png` — transparent logo
- `assets/stravantics-avatar.png` — square avatar for GitHub/profile use
- `assets/stravantics-github-banner.png` — wide GitHub/social banner
- `favicon.svg` — lightweight browser favicon

## Design direction

Enterprise futurism with restrained technology cues: navy, white, and electric green; generous negative space; responsive typography; subtle motion-free CSS; and no JavaScript framework.
